# Backend - Chatbot Assistant

Lihat [README utama](../README.md) untuk dokumentasi lengkap.

## Quick Start

```bash
cp .env.example .env
# Edit .env → isi OPENROUTER_API_KEY
npm install
npm run dev
```

Server berjalan di `http://localhost:3001`.

## Environment Variables Wajib

- `OPENROUTER_API_KEY` - API key OpenRouter

Lihat `.env.example` untuk semua opsi.
